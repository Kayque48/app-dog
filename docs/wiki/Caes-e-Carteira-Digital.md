# Cães e carteira digital

## Perfil do cão
| Campo | Observação |
|---|---|
| Nome, raça, nascimento, sexo | A idade é calculada a partir do nascimento |
| No cio | Só para fêmeas |
| Temperamento | Calmo, brincalhão, tímido ou agressivo |
| Costuma morder | Aparece como alerta no [[Descobrir-e-Match]] |
| Gosta / não gosta | "Ama morder bolinha", "odeia chinelo" |
| Peso, cor, descrição | Vieram do documento de funcionalidades |
| Nível de atividade | Sossegado, moderado ou elétrico |
| Procura | Amizade, cruzamento ou os dois. **Cão castrado só procura amizade** |
| Foto | Upload de imagem |

## Carteira digital
- **Identidade pet:** raça, nascimento, sexo, castração, peso, cor e microchip. Alergias e observações de saúde só o dono vê.
- **Vacinas:** registro de aplicação e reforço. Define se o cão está "em dia" (ver [[Regras-de-Negocio]]).
- **Documentos:** pedigree, exames, RG animal, receitas e outros (PDF ou foto). **Só o dono vê.**
- **Pedigree:** é enviado para a [[Moderacao]]. Se for aprovado, o cão ganha o selo **"Pedigree verificado"** no perfil e no Descobrir.

## Histórico
- **Do cão:** cadastro, vacinas, encontros combinados, inscrições em eventos, agendamentos, pedigree e **incidentes confirmados**.
- **Do dono:** os cães que tem e os que já teve. Remover um cão não apaga o histórico, ele vai para "cães que já tive".
